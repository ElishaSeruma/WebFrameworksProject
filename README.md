# Manchester United 26/27 Stats Analyzr

Stats Analyzr is a website for following Manchester United's 2026/27 Premier League season.

**Live site:** [webframeworksproject-nqn2.onrender.com](https://webframeworksproject-nqn2.onrender.com/)

## What you can do

- **Create an account** and pick your favourite player.
- **Log in** to see the squad.
- **Browse the full squad** with each player's photo, nationality, age and season stats: goals, assists, yellow and red cards, and minutes played.
- **Filter by position** to see only goalkeepers, defenders, midfielders or attackers.
- **Meet the coaching staff** behind the team.

## Built with

Node.js, Express, Pug, Bootstrap and MongoDB, as part of a Web Frameworks module project.

*Stats shown are sample numbers.*
